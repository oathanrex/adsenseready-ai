# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2026.x  | :white_check_mark: |
| < 2026  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **AdSenseReady-AI**, please do NOT create a public GitHub issue.

Instead, please send an email to **[oathanrex@gmail.com](mailto:oathanrex@gmail.com)** with:
- Description of the vulnerability and attack vector
- Steps or proof-of-concept script to reproduce the issue
- Potential impact and recommended mitigation

We aim to acknowledge receipt of all reports within 48 hours and provide a coordinated disclosure timeline.
